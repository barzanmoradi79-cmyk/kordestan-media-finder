# پایش رسانه‌های مجازی کردستان — نسخه آزمایشی

این پروژه یک رابط وب ساده برای جست‌وجوی صفحات عمومیِ نمایه‌شده در وب درباره کلیدواژه‌های کردستان می‌سازد.

## اجرای محلی
1. Python 3.10 یا جدیدتر نصب کنید.
2. در پوشه پروژه اجرا کنید:
   `pip install -r requirements.txt`
3. سپس:
   `streamlit run app.py`

## استقرار آنلاین
می‌توانید فایل‌ها را در یک مخزن GitHub قرار دهید و از Streamlit Community Cloud برای انتشار استفاده کنید:
https://share.streamlit.io/

## محدودیت‌ها
این برنامه وارد اپلیکیشن‌های پیام‌رسان نمی‌شود و بانک کامل کانال‌ها/گروه‌ها را تضمین نمی‌کند.
فقط نتایج عمومی نمایه‌شده توسط موتور جست‌وجو را می‌گیرد. آمار اعضا و بازدید ممکن است در دسترس نباشد.
برای استخراج مستقیم و دقیق، اتصال مجاز و مستندات جداگانه هر پیام‌رسان لازم است.
